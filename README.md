# Onda — Manifesto

This repository hosts the manifesto and homepage for [Onda](https://projectonda.com), 
a peer-to-peer protocol for personal AIs.

The site is served via GitHub Pages from `index.html`.

For the reference implementation, see [projectonda/onda](https://github.com/projectonda/onda).

For the full manifesto in Italian and English, visit [projectonda.com](https://projectonda.com).

# Onda — Manifesto

Questo repository ospita il manifesto e la homepage di [Onda](https://projectonda.com),
un protocollo peer-to-peer per intelligenze artificiali personali.

Il sito viene servito tramite GitHub Pages dal file `index.html`.

Per l'implementazione di riferimento, vedi [projectonda/onda](https://github.com/projectonda/onda).

Per il manifesto completo in italiano e inglese, vai su [projectonda.com](https://projectonda.com).
